Stage 11 - more detailed Backrooms wallpaper

Replaces these textures (64x64, tileable) in assets/backroomsmod/textures/block/:
  wallpaper.png            plain wall: stripe bands with dashes + diamond ticks, chevron pairs, fabric weave, aged blotches
  wallpaper_stained.png    one soft water stain with a drip
  wallpaper_moldy.png      light speckle of mold near the bottom
  wallpaper_peeling.png    one curled corner with bare paper underneath
  wallpaper_scratched.png  three thin scratches

I could not see your repo, so the file names above are my guess. If your wall blocks use different texture
file names, rename these files to match (check assets/backroomsmod/models/block/ or blockstates).
wallpaper_trim (the wooden chair rail) is NOT changed.
wallpaper_generator.py is the script that draws them (python3 + Pillow) if you want to tweak colours.
